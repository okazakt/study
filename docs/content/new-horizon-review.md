### 綴り一致の再確認で見つかった問題

旧照合の「綴り一致1,164行」は、そのまま対応済み数に使えない。上表の1,146行に、別義9行と同綴りの活用9行が含まれていた。

| 見出し | 既存単語素材の意味 | 公式備考が区別する意味 |
| --- | --- | --- |
| fair | 公平な | 見本市・展示会 |
| kind | 親切な | 種類 |
| light | 軽い | 光・明かり |
| like | 好む | 〜のような |
| march | 大文字のMarch「3月」と一致していた | 行進 |
| may | 大文字のMay「5月」と一致していた | 許可・可能性の助動詞 |
| rest | 休む | 残り |
| right | 右の | 正しい・権利 |
| second | 秒 | 第2の・月の2日 |

たとえばmayの許可用法には既に文法問題がある。この9行は「学習支援が全くない9語」という意味ではなく、単語の綴り一致だけで同じ語義に対応していると誤認してはいけない9行。kindやlikeも関連する熟語の正答が存在する。

また、`book`は「予約する」だけで「本」の独立語彙問題がない、`cook`は「料理人」だけで「料理する」の独立語彙問題がない等、一般的な別義の補強を120行で推奨した。うち9行が上記の公式備考による区別、残り111行は一般学習上の補強案であり、本文でその用法が使われると確認した件数ではない。

### 活用形と短縮形の扱い

- `went`、`bought`、`teeth`などは既に文法問題でも直接問われている。原形素材だけの有無と区別して正答・熟語穴の証拠IDを記録した。
- `born`を、動物の「クマ」のbearへ意味対応させない。学習上はbe bornのまとまりで扱う。
- `lives`はlifeの複数／liveの三単現、`rose`はriseの過去／バラ、`thought`はthinkの活用／思考という名詞を区別。掲載文脈なしに片方へ断定しない。
- `he’s`や`it’s`はis／has、`I’d`はwould／hadなどの複数の展開を保持。問題では文脈で一意になるようにする。
- `(1970)s`、`(Riko)'s`、`-based`は特定の数字や人名を覚えさせず、年代・所有格・接辞の規則として扱う。

### 補強優先順を確定

1. 456行の独立語彙候補から基本語・一般的な連語を追加。job、advice、good、great、danger、trouble、body、group、time、world、university等を先に扱う。456は行数であり、最終的な追加素材数の保証ではない。
2. 別義9行と、book・cook等の頻出別義を補強。既存熟語・文法で直接問えている部分は重複を見て設計する。
3. 活用・短縮形・機能語は既存の直接出題と照合し、不足する用法を短文で追加。原形があるだけで活用まで完了としない。
4. その他の語彙、地理・文化の名称、略語を必要性に応じて追加。教科書の語順・学年・単元はこの一覧から推測しない。

## 文法：主要項目の代表問はあるが、全用法確認は残る

[東京書籍の年間指導計画](https://ten.tokyo-shoseki.co.jp/text/chu/list/keikaku/)の各学年の「文法事項・表現」列を確認。一般的な文法項目を内部の点検軸にし、教材本文・設問は転載しない。

| 公式計画で扱う系統 | 既存の支援・代表例 | 残る確認 |
| --- | --- | --- |
| 中1：be／一般動詞、疑問詞、三単現、代名詞、進行形、過去形、There構文 | 基本判断問題を収録。今回の`why_reason_answer`、`there_question`、`how_many_there`も補充 | 肯定・否定・疑問と場面表現の組合せを逐次点検 |
| 中2：未来、接続詞、不定詞、動名詞、助動詞、比較、受け身、文構造 | 指導要領台帳に代表問あり。`jr_en_curriculum_svoc_noun`など | 同じ構文の用法差・会話上の使い分け。全ての年間計画行の一対一承認は未完了 |
| 中3：現在完了／完了進行、不定詞構文、間接疑問、分詞、関係代名詞、仮定法 | `perfect_continuous`、`wish_were`、`relative_which_subject`等。今回`perfect_just`、`perfect_yet_question`、`relative_that_object`、`help_infinitive_forms`を補充 | that節／what節を伴う授与構文、主語を修飾する関係節、helpの別形等を資料行別に精査 |
| 音・文字、聞く・話す、長い本文を使う活動 | 暗記・短い判断の補助に限定 | 音声理解・発話・本文全体の読解を網羅したとは扱わない |

文法240素材と読解48素材があっても、NEW HORIZONの全内容対応完了とはしない。今回の10ポイントは各2文脈を追加済み。次の拡充は教科書対応表を増やすことより、上記の共通教材の不足を埋めることを優先する。

## 再現用データ

全行精査は `python3 scripts/new-horizon-main-review.py <nh.xlsxのパス>` で再生成する。原本のSHA-256と、精査時点の既存素材の英語・日本語を固定し、原本や既存語義が変更されたら再確認を求める。全行の重複・欠落、Excelの連番、分類範囲を確認する。追加候補の一般的な意味は独自に記述し、原本Excelや教科書本文はアプリに同梱しない。
