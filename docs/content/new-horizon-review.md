# NEW HORIZONを基準にした補強確認

確認日：2026-11-05。2025年度版・2026年度使用。ユーザー指定による内部照合の主軸であり、市場占有率を検証したという意味ではない。利用者に教科書を選ばせず、共通分類で出題する。

## 語彙：追加補強は必要

[公式語彙Excel](https://ten.tokyo-shoseki.co.jp/text/chu/eigo/download/documents/eigo_19goidata.xlsx)を既存英語2,940素材と照合した。

| シート | 掲載行 | 綴り一致のみ | 要確認 |
| --- | ---: | ---: | ---: |
| 本文Word List | 1,789 | 1,164 | 625 |
| 題材語 | 93 | 1 | 92 |
| Word List外 | 520 | 179 | 341 |

綴り一致は語義・全用法の一致を意味しない。未一致には活用形（ate、been等）、短縮形、機能語、固有名詞、複合表現が混ざる。625をそのまま不足単語数として追加しない。語彙Excelには学年・単元の情報がなく、推測で教科書単元へ割り振らない。

**優先補強候補**：job（仕事）、advice（助言）、good（よい）、great（すばらしい）、danger（危険）、trouble（困難）、bake（焼く）、beauty（美しさ）、favorite（お気に入りの）。これらは見出しとして未収録で、独立した語彙問題を追加する価値がある。既存問題文中の登場と、当該語を学ぶ問題の収録は区別する。この9語は第一候補であり、全不足語の確定数ではない。

次は①基本語の独立問題、②既存語の別義、③不規則変化・短縮形を文脈で問う文法、④題材語のうち受験で使う一般語、の順に補強する。固有名詞を機械的に大量追加しない。

## 文法：主要項目の代表問はあるが、全用法確認は残る

[東京書籍の年間指導計画](https://ten.tokyo-shoseki.co.jp/text/chu/list/keikaku/)の各学年の「文法事項・表現」列を確認。一般的な文法項目を内部の点検軸にし、教材本文・設問は転載しない。

| 公式計画で扱う系統 | 既存の支援・代表例 | 残る確認 |
| --- | --- | --- |
| 中1：be／一般動詞、疑問詞、三単現、代名詞、進行形、過去形、There構文 | 基本判断問題を収録。今回の`why_reason_answer`、`there_question`、`how_many_there`も補充 | 肯定・否定・疑問と場面表現の組合せを逐次点検 |
| 中2：未来、接続詞、不定詞、動名詞、助動詞、比較、受け身、文構造 | 指導要領台帳に代表問あり。`jr_en_curriculum_svoc_noun`など | 同じ構文の用法差・会話上の使い分け。全ての年間計画行の一対一承認は未完了 |
| 中3：現在完了／完了進行、不定詞構文、間接疑問、分詞、関係代名詞、仮定法 | `perfect_continuous`、`wish_were`、`relative_which_subject`等。今回`perfect_just`、`perfect_yet_question`、`relative_that_object`、`help_infinitive_forms`を補充 | that節／what節を伴う授与構文、主語を修飾する関係節、helpの別形等を資料行別に精査 |
| 音・文字、聞く・話す、長い本文を使う活動 | 暗記・短い判断の補助に限定 | 音声理解・発話・本文全体の読解を網羅したとは扱わない |

文法240素材と読解48素材があっても、NEW HORIZONの全内容対応完了とはしない。今回の10ポイントは各2文脈を追加済み。次の拡充は教科書対応表を増やすことより、上記の共通教材の不足を埋めることを優先する。

## 再現用データ

[行別綴り照合・原本ハッシュ](new-horizon-audit.json)にURL、SHA-256、シート・行、候補IDを保持。年間計画は文法列と参照行を保持するが、各行の意味照合完了を表さない。`python3 scripts/new-horizon-audit.py <資料ディレクトリ>`で再生成（openpyxlを使用）。原本Excelはアプリに同梱しない。既存の[指導要領台帳](english-curriculum-audit.json)も併用し、教科書1社を必修範囲そのものとは扱わない。
