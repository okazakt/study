# 中学国語の拡充状況

更新：2026-11-07 / v0.68.0。**中学国語全体は未完。小学配当漢字は中学の完成対象から除外する。**

中学国語は **1,554素材・2,510生成問題**。実数は [japanese-progress.json](japanese-progress.json)。小学向け235素材を別枠へ移したため、v0.67.0の「小学の復習を含む総数」とは母数が異なる。データや学習記録を削除したわけではない。

今回、中学の漢字書きを300字追加した。全て既存の読みIDへの追加で、新しい読み問題を重複登録していない。600部品回答段階を追加し、書きは **71字から371字**へ拡充した。

## 中学漢字の対象

ユーザー指定により、中学の漢字は**小学配当1,026字を除いた常用漢字1,110字**を対象にする。小学漢字は小学の部を作る際に扱い、中学の進捗を増やすための復習分として加算しない。

字種の母数は [文科省の現行国語解説](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2019/03/18/1387018_002.pdf)、文化庁の常用漢字表、文科省の小学配当で照合済み。中学の個々の字の学年別分類は共通分類の暫定値であり、公式の固定配当や特定教科書への準拠とは区別する。

| 対応事項 | 現状 | 残作業 |
| --- | --- | --- |
| 中学で追加する漢字の読みの字種 | **1,110 / 1,110字** | 全音訓・語義を収録したという意味ではない |
| 中学の漢字書き | **371 / 1,110字** | **残り739字** |
| 複数の音訓・文脈別の使い分け | 最低一語を中心に収録 | 追加音訓・付表の語等を照合 |
| 実際の手書き・筆順 | 部品選択とは異なる技能 | ゲーム単独の習熟保証の対象外 |

[字種ごとの読み対応表](japanese-source/kanji-reading-map.json)。今回の書きは [作問元](japanese-source/secondary-writing-additions.tsv) と [差分記録](japanese-source/secondary-writing-audit.json)。

## 小学向けの保管

既存235素材は `school_level: 小学` と、公式の小学校配当学年へ分類し直した。問題ID・語句・正答・候補・学習記録は維持している。現在の学校選択は中学／高校のみなので、中学の学年・受験用・全てからは出題しない。小学のメニューはまだ作らない。

削除した小学専用単元だけを以前選んでいた設定は、同じ中学コースの有効な全単元へ戻し、開始できない状態を避ける。ユーザーが意図的に何も選ばない `[]` は維持する。
