# 中学国語の拡充状況

更新：2026-11-07 / v0.66.0。**今回は大規模拡充の第1段階。中学国語全体の完了宣言ではない。**

国語は90素材・177生成問題から、**1,477素材・1,717生成問題**へ拡充。新規は漢字読み1,098素材と、その他289素材（442生成問題）。既存の問題ID・回答履歴・漢字部品の出題は維持する。実数は [japanese-progress.json](japanese-progress.json)。

## 漢字の対応母数

[文科省の現行解説](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2019/03/18/1387018_002.pdf)では、読みは小学校1,026字に加えた常用漢字1,110字について、中1で300〜400字、中2でさらに350〜450字、中3で残りの大体を扱う。中学の個々の漢字の固定的な学年別配当表はない。書きは小学校配当漢字の習熟が中心。読みの1,110字と書きの1,026字を混同しない。

| 対応事項 | 現状 | 判定 |
| --- | --- | --- |
| 小学配当以外の常用漢字の字種 | 1,110 / 1,110字に語の読み問題を登録 | 字種の出題先は揃った |
| 各字の全ての音訓・語義 | 現在は各字最低一つの語を中心に収録 | 未完・追加の語彙照合が必要 |
| 小学配当の書き | 12 / 1,026字に部品選択 | 未完・次の大きな作業 |
| 小学配当以外の書き | 12 / 1,110字に部品選択 | 未完・入試対策として順次拡張 |
| 実際の手書き・筆順・書写 | 4択の部品選択とは異なる | このゲーム単独の習熟保証の対象外 |

例語と読みは文化庁の公開表を主軸に照合。漢字の母数は文化庁2,136字と文科省の小学1,026字の差集合で確定した。元の字・新規問題・既存問題の対応は [字種ごとの対応表](japanese-source/kanji-reading-map.json)。学年区分は共通分類の暫定値で、教科書や漢検の正式準拠を示さない。参考配分350/400/360字から、既存12字は元の学年・IDを保っている。

学習指導要領は問題の語彙リストや固定問題数を定めるものではないため、文法等に数量だけで「100％網羅」という率は付けない。今回、知識・技能の主要な柱に出題先を置いたが、一例の存在を全ての適用・技能の習熟完了とはしない。

長文読解・作文・討論・実際の朗読や書写そのものを4択で代替するのではなく、その際の**解き方・読み方・判断のポイントを覚える**という既定方針を維持する。長い図＋長文＋長い選択肢は追加しない。

## 今後の優先順

1. **漢字書き**：小学配当の不足1,014字を母数に、正しい部品分割・位置・字形の候補を作る。独体字は無理に偽の部品へ分割せず、扱いを明示してから追加する。中学の追加字種の書きも入試頻出から並行補強する。
2. **読みの深さ**：一字一語の対応を超え、公式の中学校段階の音訓・付表の語、同字異音・文脈違いを照合する。正しい別読を誤答にしない。
3. **知識の適用**：助詞・助動詞・活用、重要古語、訓読の短い適用問題を厚くし、ことわざ・故事成語を増やす。
4. 最後に項目別対応表と残件を見直し、このゲームの暗記・ポイント学習としての完了範囲を明確にする。

## 確認方針

基本テスト・全問画面表示・5分進行検証は行っていない。新規分だけのJSON・ID・必須項目・4択・文字量の簡易チェックを実施。高さ推定超過の代表7例×28表示のみを確認し、同じ範囲を再利用できる条件付きの表示予算を登録した。新しい読み専用データは漢字読みにだけ現れ、漢字書きの候補へ入らないことをデータ生成時に確認した。
