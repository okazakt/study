# 中学国語の拡充状況

更新：2026-11-07 / v0.67.0。**中学国語全体は未完。第2段階として漢字書きと適用問題を拡充した。**

国語は **1,789素材・2,615生成問題**。初期は90素材・177生成問題。実数は [japanese-progress.json](japanese-progress.json)。

今回、漢字書きを282字追加（小学配当223字・小学以外59字）。小学配当の223字は新規の読み／書き素材とし、59字は既存の読みIDに書きを追加した。書きは全ての部品を順に問う566段階を追加。さらに現代文法43・古文20・漢文10・ことわざ20の93素材／113問を追加した。差分は新規316素材・既存59素材の強化、追加902生成問題。

## 漢字の対応母数

[文科省の現行解説](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2019/03/18/1387018_002.pdf)では、読みは小学校1,026字に加えた常用漢字1,110字について、中1で300〜400字、中2でさらに350〜450字、中3で残りの大体を扱う。個々の漢字の固定的な中学学年別配当表はない。書きの規定は小学校配当漢字の習熟が中心。読みの1,110字と書きの1,026字を混同しない。

| 対応事項 | 現状 | 判定 |
| --- | --- | --- |
| 小学配当以外の常用漢字の字種 | 1,110 / 1,110字に語の読み問題 | 字種の出題先は揃った |
| 各字の全ての音訓・語義 | 各字最低一つの語を中心に収録 | 未完・追加照合が必要 |
| 小学配当の書き | **235 / 1,026字**に部品選択 | 残り791字 |
| 小学配当以外の書き | **71 / 1,110字**に部品選択 | 入試対策として順次拡張 |
| 実際の手書き・筆順・書写 | 部品選択とは異なる技能 | ゲーム単独の習熟保証の対象外 |

字種は文化庁2,136字と文科省の小学1,026字の差集合で照合。[字種ごとの読み対応表](japanese-source/kanji-reading-map.json)。学年は共通分類の暫定値で、教科書や漢検への正式準拠を示さない。今回の小学配当分は中1での復習として登録し、中学の追加字種は元の学年を維持した。

## 今後の優先順

1. **漢字書き**：小学配当の残り791字を優先。上下・囲みなど、まだ登録していない構成を代表確認して再利用できる形にする。独体字は無理に分割せず、扱いを明示して追加する。中学の追加字種も入試頻出から並行補強する。
2. **読みの深さ**：公式の中学校段階の追加音訓・付表の語・同字異音を照合する。正しい別読を誤答にしない。
3. **知識の適用**：重要古語・訓読・文法の別表現を補強し、項目別の残件を見直す。

## 表示・確認の運用

基本テスト・全問表示・5分進行は実施しない。新規・変更分だけのJSON・ID・4択・字形・文字量の簡易チェックを行った。

今回、左右の2部品／左と右上下の3部品を代表する6例と、長いことわざ2例を320/390×844・通常/学習集中で確認（32表示）。ことわざは初期の長い説明が収まらなかったため短縮し、確認済み。境界の正答表示4件と復習の途中／完成時も確認した。同じ寸法範囲の1文字候補の修正は再計測をしない。

[文字量予算](content-budget.md)には、今回確認した漢字の構成・文字量・幅の条件を登録。単に図フラグがあるだけで毎回全件確認することはせず、登録した左右構成ならデータチェックだけで追加できる。長い熟語見出しと説明選択肢の組合せは別条件で検出する。
