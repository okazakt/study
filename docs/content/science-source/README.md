## 出題データと再生成

- `foundation-terms.tsv`：120用語。用語と説明の両方向240問を生成する。@見出しは学年・分野・単元・公式内容ブロック。各行は用語、説明文、空欄の正答、候補3件、補足、任意の用語候補3件。分類で上位概念と下位概念を正誤に混ぜないため、植物・動物、電池、反射や化学変化などは候補を明示する。
- `foundation-choices.tsv`：実験条件・器具・比例・単位・典型的な誤りの80問。画像や特殊な数式レイアウトは追加しない。
- `foundation-overrides.json`：新規素材の編集上の分類補正。圧力は現行の気象分野の扱いに沿って中2・地学へ、全エネルギーの保存は第1分野(7)へ対応させる。
- `python scripts/build-science-content.py` で既存 `junior_science.json` の末尾へ追加。自分のバッチのみ再生成し、元89素材を維持する。IDは分野と用語、または設問から安定生成。別ファイルの68素材も変更しない。
- `node scripts/science-progress.mjs` で理科全体の実数・学年・分野・公式内容ブロック別のIDを更新する。既存素材は単元などから報告上の対応を整理し、問題本体は変えない。

学年は共通の暫定分類。教科書・学校の進度を保証しない。v0.85.1以降、体の働き・地学・量的関係・科学技術を段階的に追加し、v0.88.0で公式小項目を照合した。[進捗と残作業](../science-progress.md)。

## 内容上の注意

- ばねの比例範囲、同じ質量・同じ抵抗・同じ時間、出入りのない系など、成立条件を必要な箇所に付ける。位置と運動のエネルギーの保存は重力のみが仕事をする場合などと区別し、全エネルギーの保存と混同しない。
- イオンの電荷・電子の移動、電流の向き、動静脈と動静脈血、分類の上位下位、質量と重さなどを区別する。
- 蒸留の最初の液は薄い溶液よりエタノールの割合が高いことを問い、完全に純粋な液になるとはしない。示相化石は造礁サンゴと指定し深海性の例との曖昧さを避ける。
- 出題テーマは必要な対象を示す。直接正答を含む場合のみ伏せ、伏せた説明だけでも対象が明確な文にする。
- 図表の実読取り、作図、長い実計算、実際の器具操作・観察・実験は別練習。ここでは条件・着眼点・短い判断を扱う。
