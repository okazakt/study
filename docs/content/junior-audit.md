# 中学5教科：収録状況・必要範囲・追加量の見積もり

基準日：2026-11-01／アプリv0.47.0。対象は合意済みの「高校受験に向けた暗記・短い解法判断の支援」。長文総合問題、長い実計算、作文・証明の記述完成、リスニング・会話等の実技はこの見積もりの対象外。

英語の大規模追加後の最新状況は[英語進捗](english-progress.md)を参照。以下の件数はv0.47.0時点の監査スナップショットとして保持する。

## 結論

現状は全学年でプレイできる初期問題集。主要な分野名は多く登場するが、単元内の学習項目はまだ少ない。英語の語彙、国語の漢字、社会の各時代・地域、理科の生物以外の充足が大きな作業となる。

- 現在は479素材、882生成問題。素材は語句や題材の元データ、生成問題は逆方向・各空欄・綴り・漢字部品を含む回答段階の数。
- 数学の数値変更は11ポイント・296通り。数値の違いは問題数へ加算しない。
- 同じテーマの一般説明と適用例なども別素材になっており、479素材をそのまま独立した479知識とも扱わない。例えば係り結び、返り点、社会権等の既存素材と追加問題は、共通ポイント・別の適用ポイントの整理が必要。
- 必修・入試頻出・発展の区分、学習項目ごとの正確な分母が未整備。したがって現時点で教科全体の「網羅率○％」は算出しない。
- 以下の目標数は開発規模を判断するための編集上の仮置き。学習指導要領の公式問題数でも、未作成問題の確定件数でもない。学習項目の分割、多義語、漢字の読み、教科書の差分で増減する。

## 状態の読み方

- **一部収録**：該当する学習ポイントがあるが、分野・単元の充足は未達。
- **入口のみ**：代表的な1〜数ポイントが中心。周辺の必須事項の追加が必要。
- **重点的に収録**：他の分野より多く素材がある。必修範囲や問題の質を照合した「網羅済み」の意味ではない。
- **未収録**：該当データ・機能がない。

現在、単元全体を内容面まで「網羅済み」と認定したものはない。難しそうな問題を増やす前に、基本事項の抜けを埋める。

## 追加量の概算

### 見積もりの前提

「入試頻出の共通知識・解法ポイントを広く収録する版」を仮の計画対象とする。以下は正式な全教科書・全語義・全漢字の全読みを保証する上限ではない。教材の採用一覧を確定し、重複を整理した時点で再見積もりする。

- 国語：漢字・読み書きの題材を約900〜1,100、語句を約200〜300、現代文法・古文・漢文・読み方を計約200〜400とする仮置き。1字の複数の読み・語によって素材数は増える。字数と語数は同じではない。
- 英語：復習語を含む単語約2,200〜2,500、熟語等約150〜300、文法・短い読みのポイント約150〜300を仮置き。全出版社を合わせた語彙や多義語の範囲次第で上振れする。
- 数学・理科・社会：単元の知識と短い判断ポイントを細分化した編集上の仮置き。内部の数値・表現バリエーションは素材数に加算しない。

### 段階の区切り

1. **主要事項を揃える版**：まず全体約1,700〜2,400素材を目安に、各単元の基本を優先。教科別の仮置きは国語300〜450、英語600〜900、数学130〜180、理科280〜400、社会350〜500（合計1,660〜2,430）。現在から約1,200〜2,000素材の追加。網羅完成とは呼ばない。
2. **入試頻出の収録を広げる版**：上の最終規模の仮置きへ進め、各単元の不足を学習項目表で再点検。
3. **教科書対応・適用パターンを充足**：照合資料が得られたものから並行して進める。語彙等を教科書ごとに複製せず、同じ素材へ対応情報を足す。

追加4,651〜6,331素材は、100〜150素材ずつ内容・表示を検証する単位なら、単純換算で約32〜64区切り。これは内部の検証単位の目安であり、ユーザー確認の必要回数や会話の回数の見積もりではない。漢字の字形・数値生成・図表等は同じ素材数でも作業量が増える。

教科書計30冊分の対応表は共通問題の追加量と別の照合作業。改訂版は旧版を残して追加し、利用中の設定を自動で切り替えない。高校の教科書対応は対象外。

## 次に進める順序

1. 全項目を一つずつ管理できる台帳へ細分化し、必修・頻出・発展と重複を整理。
2. 英語の単語・熟語、国語の漢字・語句を優先して数量を増やす。
3. 理科の生物以外、社会の各地域・時代・経済の抜けを埋める。
4. 数学の未収録の判断ポイントと、図・数値生成の対象を補充。
5. 教科書資料の照合と、必要な表示機能を並行して進める。
