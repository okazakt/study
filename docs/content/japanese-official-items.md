# 中学国語：学年別の公式項目との対応

更新：2026-11-08 / v0.78.0

文部科学省『中学校学習指導要領解説 国語編』付録3、印刷頁158〜163を参照。項目名は要約で、全文転載ではない。

第2・各学年2内容の知識及び技能とA/B/C(1)をイロハ細目で数える。書写は親項目を内側の細目に置き換えるため81行。A/B/C(2)の言語活動例23行は別記。公式が完了率用に定義した項目数ではない。目標・授業時数など指導計画は出題項目数へ算入しない。

同じ学年のコースに出る素材のみを対応IDとして掲載する。知識ポイントの出題先を示し、実技能の履修・習熟の代替ではない。

**81項目すべてに同学年の知識・判断問題を対応付けた。各項目の全要素・用例や実技を網羅したという完了判定ではない。** 小学漢字の実書はユーザー指定により保留。中学漢字の学年配当は暫定分類で、文科省による字別固定配当ではない。

v0.77.0で学年別の不足へ26素材を追加。v0.78.0で追加音訓・付表語の補強と内容確認を実施し、[基礎版整備を一区切り](japanese-completion.md)とした。既存のIDと回答履歴、選択肢は維持。
