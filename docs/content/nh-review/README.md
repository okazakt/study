# 本文Word Listの編集判断

NEW HORIZONの公式本文Word List全1,789行（Excelの2〜1790行）を2026-11-05に精査した入力台帳。公開されている見出し語と少数の備考を、既存素材の英語・日本語および独自の学習用語義に照らして確認したもの。教科書本文の全掲載文脈・全語義の照合済みという意味ではない。

- `review-scope.json`：対象・原本URL・SHA-256。原本が変われば再確認。
- `existing-entries.json`：綴り一致1,164行の既存ID・英語・日本語の精査時点のスナップショット。再生成時に意味の変更を検出する。
- `lexical-additions.tsv`：独立した語彙教材を追加する456行。ファンの2義を別行に含むため、見出しの綴りは455種類。出版社の訳文ではなく独自の学習用説明。
- `forms-and-functions.tsv`：未一致169行の原形・展開形・扱い方。単独語彙を無理に大量追加せず、活用・文法・名称などの適切な出題へ分ける。
- `sense-expansions.tsv`：綴り一致側で補強を推奨する120行。うち9行は公式備考が明示する別義と既存単語素材の語義が異なる。残り111行は一般的な重要別義の補強案であり、当該教科書本文でその義が使われると確認した数ではない。

各入力を読んで `python3 scripts/new-horizon-main-review.py /path/to/nh.xlsx` を実行すると、全行のJSONと閲覧用Markdownを再生成する。入力範囲の重複・欠落・備考付き語の区別、原本ハッシュ、既存語義の変更を確認する。新しい素材が追加された場合、追加済みの行の編集判断も更新する。再生成だけで追加済みへ自動承認しない。

`directAnswerOrPhraseBlankIds`は、既存素材の正答または熟語の穴の正答文字列と一致する参考証拠。問題文に登場するだけの単語を収録済みに数えない一方、独立した語彙見出しがなくても文法・熟語で直接問われている場合を見落とさない。文法用法や教科書語義の完全一致を自動認定する項目ではない。

本文Word List以外の2シートは今回の精査対象に含めない。旧 `new-horizon-audit.json` は3シートの綴り候補一覧として保持し、本文の最終判断は `new-horizon-main-review.json` を参照する。
