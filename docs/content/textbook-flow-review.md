# 教科書フローの見直し案

確定：2026-11-05。ユーザー承認により教科書別の振り分けを廃止し、以下の共通導線を採用。NEW CROWNでなくNEW HORIZONを内部照合の主軸とする。

## 公開資料の確認範囲

「単元別の新出語を全範囲で取得できる」「総語彙一覧がある」「一部単元の補助教材がある」「指導書等にはデータがある」は別の状態。検索で見つからないことを非公開の証明にしない。現行の2025年度版／2026年度使用を対象とし、旧版のデータや高校版を混同しない。

| 教科書 | 現時点で確認できた公式資料 |
| --- | --- |

したがって「ONE WORLD・NEW CROWN以外は単元別英単語を公開していない」とは、現状の確認では言えない。一方、6社すべてについて同じ範囲・精度の単元別語彙を揃えられる状態でもない。

## 推奨する通常導線

学校区分 → 教科 → 学年・受験用 → 学習分野 → 単元・範囲 → プレイ。

英語なら、単語・熟語・英文法・読解のポイントから選び、共通の学習分類で範囲を絞る。教科書を選ばないことが、機能欠落や未設定のように見えない構成にする。定期試験向けに教科書全社の範囲へ対応しているという表示はしない。

## 確定した扱い

**v0.63.0確定方針：教科書別の選択・出題制限は廃止。共通の学年・受験用→学習分野→単元・範囲で選択する。教科書対応表は内部研究資料としてのみ保持し、NEW HORIZONを不足確認の主な参照軸にする。**

旧 `study-beat-textbooks-v1` は削除せず、出題条件として参照しない。回答履歴・素材ID・旧回答の教科書メタデータは保持する。アプリの起動とキャッシュは教科書対応表に依存しない。
