## 参照資料

[文科省・中学校学習指導要領（平成29年告示）解説 社会編](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2019/03/18/1387018_003.pdf)の付録3（印刷頁202以降）に掲載された各分野の「2 内容」および対応する解説を参照。取得日・SHA256は `curriculum-blocks.json` に記録。公式資料からブロックの見出しと対応を整理し、設問・選択肢・説明は独自に作成した。教科書本文・図版の複製ではない。

## 作問元と再生成

- `foundation-terms.tsv`：188用語。@見出しごとの4語を用語の候補とし、各語の穴埋め候補は個別に指定。同じ語義の言い換えを正誤にしない。説明→用語、用語→穴埋めの両方向を生成する。
- `foundation-choices.tsv`：地域の特色、歴史の方法、効率・公正などの32問。
- `python scripts/build-social-content.py` で既存の `junior_social.json` へ追加。独自バッチだけを置き換えるため再生成は冪等。IDは分野＋用語、または分野＋設問の安定ハッシュ。以前の12素材および別ファイルの58素材は変更しない。
- `node scripts/social-progress.mjs` で社会の実数とブロック別のIDを更新する。`curriculum-blocks.json` の残作業欄を今後の追加に合わせて見直す。

## 内容と学年・確認日

地理・歴史の配当学年は学校・出版社によって異なるため共通の暫定分類を使い、分野・単元の対応を優先する。公民は中3。全ての中学社会の必修語句が一つの公式固定リストに列挙されているとは扱わない。

今回の制度確認日は2026-11-08。法制度の現行の話と、1947年制定などの過去の出来事を区別する。統計の順位・割合を追加する際は対象年と出典を保持し、年なしの「現在」問題にしない。

テーマに穴の正答が直接含まれる場合は伏せる。ただしテーマを伏せるだけで複数の答えが成立する問題にはしない。北緯・南緯は対象と範囲を明確にし、日清戦争の相手国は年代と文脈を併記する。

## 表示確認

既存の文字のみ4択・穴埋めを使う。長い条約名・国名などを含む6例だけを通常／学習集中、幅320／390の実HTML/CSSで確認し、文を短縮。機械用の予算は `content-budget.json` の `social-foundation-text-20261108`。記録は `layout-review.json`。同じ構成・上限内の追加では基本テストや画面確認を繰り返さない。

境界確認は静的な完全表示状態でのChromium計測。全端末の保証や実プレイの検証ではない。全問ブラウザ表示・5分シミュレーションは行っていない。

## 第2回の追加（v0.80.0）

`regions-terms.tsv` の160用語と `regions-choices.tsv` の80問、計240素材／400問を追加。世界各州・日本7地方、歴史の文化・産業・政治の変化、公民の制度比較を補強する。確認日は2026-11-08。統計の最新順位は追加せず、地理・歴史の学年は暫定の共通配当。

用語行には任意の第6列で、既存の用語を含む3つの候補を明示できる。異なる分類軸や単なる類義語によって別解が成立しないよう、同じ対象の比較を優先する。`regions-overrides.json` で飛鳥・天平文化の学年・単元と、五街道・三審制のテーマ表示を明示的に補正する。ゲーム本体の選択肢生成方法は変えない。

ビルダーはfoundationとregionsの2バッチを作問元から再生成する。初期素材と、前回までの全290社会素材の内容・IDが不変なことを確認。今回分は `--batch social-regions-20261108` で文字量を確認し、前回の社会用上限内のためブラウザや実プレイの再確認は行わない。差分は `regions-audit.json`。社会全体はまだ補強中。
