## 作問元と再生成

- `python scripts/build-social-content.py` で既存の `junior_social.json` へ追加。独自バッチだけを置き換えるため再生成は冪等。IDは分野＋用語、または分野＋設問の安定ハッシュ。以前の12素材および別ファイルの58素材は変更しない。
- `node scripts/social-progress.mjs` で社会の実数とブロック別のIDを更新する。`curriculum-blocks.json` の残作業欄を今後の追加に合わせて見直す。

## 内容と学年・確認日

地理・歴史の配当学年は学校・出版社によって異なるため共通の暫定分類を使い、分野・単元の対応を優先する。公民は中3。全ての中学社会の必修語句が一つの公式固定リストに列挙されているとは扱わない。

今回の制度確認日は2026-11-08。法制度の現行の話と、1947年制定などの過去の出来事を区別する。統計の順位・割合を追加する際は対象年と出典を保持し、年なしの「現在」問題にしない。

テーマに穴の正答が直接含まれる場合は伏せる。ただしテーマを伏せるだけで複数の答えが成立する問題にはしない。北緯・南緯は対象と範囲を明確にし、日清戦争の相手国は年代と文脈を併記する。

## 表示確認

既存の文字のみ4択・穴埋めを使う。長い条約名・国名などを含む6例だけを通常／学習集中、幅320／390の実HTML/CSSで確認し、文を短縮。機械用の予算は `content-budget.json` の `social-foundation-text-20261108`。記録は `layout-review.json`。同じ構成・上限内の追加では基本テストや画面確認を繰り返さない。

境界確認は静的な完全表示状態でのChromium計測。全端末の保証や実プレイの検証ではない。全問ブラウザ表示・5分シミュレーションは行っていない。

## 第3回：地理の補強（v0.81.0）

`geography-terms.tsv` の68用語（両方向136問）、`geography-choices.tsv` の112問、`prefecture-capitals.tsv` から生成する44問、計224素材／292問を追加。位置問題24問、領域・時差・気候・資源・産業・交通・防災・資料の着眼点を含む。県庁所在都市の確認先は47件とし、既存3都市を再利用する。全件が同じ出題形式で両方向に出るという意味ではない。東京都は「東京都庁がある特別区」として問う。
