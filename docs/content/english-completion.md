# 英語の完成条件と残作業

v0.52.0。通常プレイで暗記・判断のポイントを学べる共通問題集を対象とする。数量だけで完成としない。2026年版教科書の単元対応は、共通問題集とは別の完了条件とする。

| 項目 | 現在の根拠 | 残る作業・完了条件 |
| --- | --- | --- |
| 基礎・頻出語彙 | 単語1,639素材。英和・和英・文字数を揃えた段階的綴り | 学習指導要領の語数だけを充足基準にせず、候補語台帳と収録語を照合。不足・品詞・多義・小学校復習語と発展語の偏りを整理する。数量仮置きとの差は561〜861語 |
| 頻出熟語 | 186素材。両方向と重要語の穴埋め | 追加候補を照合し、語法・前置詞の別解を点検。数量仮置きの上限との差は114素材 |
| 名詞・代名詞・数量・冠詞 | 単複・不規則複数、所有・目的格・再帰、可算と不可算、各種数量表現、冠詞の音など | 代表問の存在だけで充足とせず、使い分けを問う観点台帳と照合する |
| 動詞・時制・助動詞 | be／一般動詞、三単現、疑問否定、進行、過去、未来、完了・完了進行、助動詞の語形・意味 | 規則と不規則の語形、時制の選択、完了の用法、疑問否定と短い返答の不足を照合する |
| 準動詞・比較・文型・接続 | 不定詞・動名詞・分詞、原級比較と比較級・最上級、目的語と補語、条件・理由・対比など | 構文と意味の両面を点検。用例に応じた正答の一意性を確認する |
| 後置修飾・受け身・間接疑問・仮定法 | 関係代名詞、分詞、受け身、間接疑問、I wish等の代表問 | 各形式と使い分けの不足を照合する。英文法全体は160素材、数量仮置きの上限との差は80素材 |
| 読解・会話の判断ポイント | 指示語、限定・否定、時系列、条件・数量、対比、理由と目的、要点、例、推測の限界、案内と応答の48素材 | 観点ごとの代表例と適用例を点検。長文そのものを解かせず、短い文で読み方を覚える。数量仮置きの上限との差は12素材 |
| 表現の複数パターン | 文法・読解80ポイントに各2例、計160表現。元IDと累計・直近結果を共有 | 残る文法・読解への展開。意味・技能が異なる問題を無理に同じ履歴へまとめない |
| 表示・選択肢 | 各例で合計200文字以内、候補各30文字以内。小画面で確認 | 表現を増やすたびに各例を確認。構造テストだけで言語内容の正しさを保証しない |
| 教科書対応 | 未収録 | 2026年版6種×3学年の実資料で書誌・単元・掲載語を照合し、対応表と選択に反映。推測で準拠済みとしない |

数量差の合計は561〜1,067素材で、追加約600〜1,100素材を作業用に見込む。表現の追加は別問題として数えず、この数量差を減らすためだけに類似問題や発展語を水増ししない。必修項目の照合結果によって見積もりは変わる。教科書対応は資料確認まで数量・作業量を確定しない。

次は、語彙候補台帳との照合・不足語の補充、文法と読解の観点別照合、未対応ポイントへの例文展開を進める。現在の素材別実数は [英語進捗](english-progress.md) を参照。
