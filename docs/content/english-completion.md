# 英語の完成条件と残作業

v0.61.0。通常プレイで暗記・判断のポイントを学べる共通問題集を対象とする。数量だけで完成としない。2026年版教科書の単元対応は、共通問題集とは別の完了条件とする。

| 項目 | 現在の根拠 | 残る作業・完了条件 |
| --- | --- | --- |
| 基礎・頻出語彙 | 単語2,382素材。英和・和英・文字数を揃えた段階的綴り | 学習指導要領の語数だけを充足基準にせず、候補語台帳と収録語を照合。不足・品詞・多義・小学校復習語と発展語の偏りを整理する。数量仮置きの上限との差は118語。今回の基礎語候補96語はIDと対応して照合済み（全必修リストの照合ではない） |
| 頻出熟語 | 270素材。両方向と重要語の穴埋め | 追加候補を照合し、語法・前置詞の別解を点検。数量仮置きの上限との差は30素材 |
| 名詞・代名詞・数量・冠詞 | 単複・不規則複数、所有・目的格・再帰、可算と不可算、各種数量表現、冠詞の音など | 代表問の存在だけで充足とせず、使い分けを問う観点台帳と照合する |
| 動詞・時制・助動詞 | be／一般動詞、三単現、疑問否定、進行、過去、未来、完了・完了進行、助動詞の語形・意味 | 規則と不規則の語形、時制の選択、完了の用法、疑問否定と短い返答の不足を照合する |
| 準動詞・比較・文型・接続 | 不定詞・動名詞・分詞、原級比較と比較級・最上級、目的語と補語、条件・理由・対比など | 構文と意味の両面を点検。用例に応じた正答の一意性を確認する |
| 後置修飾・受け身・間接疑問・仮定法 | 関係代名詞、分詞、受け身、間接疑問、I wish等の代表問 | 各形式と使い分けの不足を照合する。英文法全体は222素材、数量仮置きの上限との差は18素材。今回補充した32観点はIDと対応して管理する |
| 読解・会話の判断ポイント | 指示語、限定・否定、時系列、条件・数量、対比、理由と目的、要点、例、推測の限界、案内と応答の48素材。全ポイントに別の文脈も収録 | 観点ごとの代表例と適用例を点検。長文そのものを解かせず、短い文で読み方を覚える。数量仮置きの上限との差は12素材 |
| 表現の複数パターン | 文法・読解178ポイントに各2例、計356表現。元IDと累計・直近結果を共有 | 残る文法・読解への展開。意味・技能が異なる問題を無理に同じ履歴へまとめない |
| 表示・選択肢 | 各例で合計200文字以内、候補各30文字以内。小画面で確認 | 表現を増やすたびに各例を確認。構造テストだけで言語内容の正しさを保証しない |
| 教科書対応 | 2026年度6種18冊の書誌と公開資料を確認し、ONE WORLDの語彙915素材、Here We Go!の文法95素材・23単元を選択可能にした | 一部対応。残る語義・未一致語句、他5社の単元別語彙、文法・読解を継続照合する |

数量目標の下限には全分類で到達。上限との差は合計178素材だが、これは確定した残件数ではない。表現の追加は別問題として数えず、この数量差を減らすためだけに類似問題や発展語を水増ししない。必修項目の照合結果によって見積もりは変わる。教科書対応は資料確認まで数量・作業量を確定しない。

次は、語彙候補台帳との照合・不足語の補充、文法と読解の観点別照合、未対応ポイントへの例文展開を進める。現在の素材別実数は [英語進捗](english-progress.md) を参照。

今回の確認範囲と出題IDは [照合台帳](english-audit.json) に記録する。語彙96候補は今回候補に挙げた基本動詞等の有限一覧。文法32観点は今回補充した項目。読解48ポイントは全てに2例あることの確認であり、読解全技能の網羅を意味しない。

一次資料に基づく現状は [指導要領・教科書照合](english-verification.md) を優先する。指導要領を60観点に分解し、代表問あり・一部支援・未実装を区別した。音声・発話・自由英作文等を、単語数や4択問題の数によって対応済みとしない。

教科書照合から補充した127語は [追加語台帳](english-textbook-basics.json) に元資料の行番号と既存素材IDを記録する。別義・文脈不足は引き続き保留する。

文法の不足12ポイントには各2例を追加。Here We Go!への対応は公開単元系統表の文法項目との対応に限り、語彙・読解・本文の対応ではない。全対応完了は0／6シリーズで、部分対応の2シリーズと区別する。
