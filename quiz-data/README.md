# 問題データの編集方針

`junior_science.json` は中3理科89件の素材です。用語回答89問と、各空欄を順に答える97問を生成します。

## 選択肢

- `term_dummies` と各 `blanks[].dummies` は、それぞれ対象の正解に対する誤答候補を3件保持する。正解を含む4件は全て異なる文字列とする。
- 同じ単元・概念群・実験操作から、実際に取り違えやすい候補を選ぶ。例：「分離の法則」に「独立の法則・顕性の法則・伴性遺伝」を並べ、電気・力学の法則は並べない。
- 穴埋めは数値の計算間違い、染色体とDNA量の混同、受粉と受精、胚珠と子房などの典型的な取り違えを用いる。本文に入れた際の文法・単位・語尾も確認する。
- 正解の同義語、正解を含む上位概念・下位概念、同じ条件で成立する別の答えは誤答にしない。たとえば核の染色液に、同じ目的に使える別の染色液を混ぜない。
- 「必ず」「だけ」といった限定や極端に長い誤答を無闇に使い、語感だけで除外できる候補を増やさない。
- 問題が基本事項である場合、紛らわしさのために複数正解にしない。難度はプレイ結果を見て調整し、単に候補を変更しただけで既存の `difficulty` 評価を引き上げない。

2026-10-30に全89件・97空欄の候補を見直しました。`npm test` は構造・候補数・重複・出題生成を確認します。内容を編集した際は、本文に全選択肢を代入し、正解が1つだけになることも確認してください。

## 中2英語

`junior_english.json` は英単語24件・熟語8件の初期セットです。中2で扱うことの多い語彙と復習語彙を含みます。教科書ごとに配当学年は異なり、網羅的な語彙表ではありません。

- `english` / `japanese`：英語と今回問う日本語の意味。多義語はこの意味に限定する。
- `english_dummies` / `japanese_dummies`：各方向の誤答3件。同じ意味になる別の英語や和訳を混ぜない。
- `spelling_template`：`{{1}}{{2}} {{3}}` のような綴りの型。熟語の空白はそのまま固定。
- `spelling[]`：`index`、正解部分`answer`、誤綴り3件`dummies`。全正解を連結すると`english`に完全一致すること。
- 分割は綴りの学習単位であり、音節・発音の分割を意味しない。ground は gr / ou / nd。選択肢は正解と同じ文字数に揃え、正しい単語の別の区切りが誤答になることを防ぐ。対象の文字数も案内に表示する。
- 和訳・英訳各32問と綴りの各部分を生成する。綴りの途中は完全な英語や補足を表示せず、意味と既に正解した部分を手掛かりにする。

## 熟語の単語穴埋め

熟語8件は`spelling_template`/`spelling`の文字分割を使わず、`phrase_blanks[]`で出題位置（1から始まる単語番号）・`answer`・`dummies`3件を指定します。対象以外の単語は表示し、指定した位置を順番に1つずつ出題します。take care ofはtake/care/ofの全3か所が対象です。候補の文字数は揃える必要はありません。同じ意味になる別表現（例えばfor exampleに対するfor instance）を誤答にしないでください。

## 中3国語と出題の間隔

`junior_japanese.json` は中3の復習・入試向け初期セット38件です。漢字12件（読み・字形選択の24問）、熟語／四字熟語8件（両方向16問）、現代文・古文・漢文文法各6件（両方向36問）の計76問を生成します。教科書の配当は異なり、全範囲の網羅や特定教科書準拠は保証しません。

- `kind: kanji`：`word`・`reading`・`reading_dummies`・`sentence`で読み。`writing_hint`・`character`・`component`・`component_dummies`・`fixed_component`で左の部品の字形を選ぶ。候補は部首名でなく字形。完成漢字は回答前の本文に書かない。読みの別の正答をダミーにしない（憧憬の「どうけい」は誤答にしない）。
- `kind: idiom`：`term`・`definition`と各方向3候補。正解の言い換え、上位概念に含まれる別の正答をダミーにしない。
- `kind: grammar`：理科と共通の`explanation_template`・`blanks`・`term_dummies`。
- 同じidの読み／書き・説明／用語・和訳／英訳は、別題材を挟んで出す。同じ説明文の複数穴は1単位として最後まで連続回答する。題材ごとの巡回順を固定し、科目別のシャッフルを混ぜる。英単語の文字綴りだけは1単位として順に連続回答する。熟語の穴は連続させない。
