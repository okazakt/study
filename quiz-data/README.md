# 問題データの編集方針

`junior_science.json` は中3理科89件の素材です。用語回答89問と、各空欄を順に答える97問を生成します。

## 選択肢

- `term_dummies` と各 `blanks[].dummies` は、それぞれ対象の正解に対する誤答候補を3件保持する。正解を含む4件は全て異なる文字列とする。
- 同じ単元・概念群・実験操作から、実際に取り違えやすい候補を選ぶ。例：「分離の法則」に「独立の法則・顕性の法則・伴性遺伝」を並べ、電気・力学の法則は並べない。
- 穴埋めは数値の計算間違い、染色体とDNA量の混同、受粉と受精、胚珠と子房などの典型的な取り違えを用いる。本文に入れた際の文法・単位・語尾も確認する。
- 正解の同義語、正解を含む上位概念・下位概念、同じ条件で成立する別の答えは誤答にしない。たとえば核の染色液に、同じ目的に使える別の染色液を混ぜない。
- 「必ず」「だけ」といった限定や極端に長い誤答を無闇に使い、語感だけで除外できる候補を増やさない。
- 問題が基本事項である場合、紛らわしさのために複数正解にしない。難度はプレイ結果を見て調整し、単に候補を変更しただけで既存の `difficulty` 評価を引き上げない。

2026-10-30に全89件・97空欄の候補を見直しました。`npm test` は構造・候補数・重複・出題生成を確認します。内容を編集した際は、本文に全選択肢を代入し、正解が1つだけになることも確認してください。

## 中2英語

`junior_english.json` は英単語24件・熟語8件の初期セットです。中2で扱うことの多い語彙と復習語彙を含みます。教科書ごとに配当学年は異なり、網羅的な語彙表ではありません。

- `english` / `japanese`：英語と今回問う日本語の意味。多義語はこの意味に限定する。
- `english_dummies` / `japanese_dummies`：各方向の誤答3件。同じ意味になる別の英語や和訳を混ぜない。
- `spelling_template`：`{{1}}{{2}} {{3}}` のような綴りの型。熟語の空白はそのまま固定。
- `spelling[]`：`index`、正解部分`answer`、誤綴り3件`dummies`。全正解を連結すると`english`に完全一致すること。
- 分割は綴りの学習単位であり、音節・発音の分割を意味しない。ground は gr / ou / nd。選択肢は正解と同じ文字数に揃え、正しい単語の別の区切りが誤答になることを防ぐ。対象の文字数も案内に表示する。
- 和訳・英訳各32問と綴りの各部分を生成する。綴りの途中は完全な英語や補足を表示せず、意味と既に正解した部分を手掛かりにする。

## 熟語の単語穴埋め

熟語8件は`spelling_template`/`spelling`の文字分割を使わず、`phrase_blanks[]`で出題位置（1から始まる単語番号）・`answer`・`dummies`3件を指定します。対象以外の単語は表示し、指定した位置を順番に1つずつ出題します。take care ofはtake/care/ofの全3か所が対象です。候補の文字数は揃える必要はありません。同じ意味になる別表現（例えばfor exampleに対するfor instance）を誤答にしないでください。

## 中3国語と出題の間隔

`junior_japanese.json` は中3の復習・入試向け初期セット38件です。漢字12件（読み12問・部品選択29段階）、熟語／四字熟語8件（両方向16問）、現代文・古文・漢文文法各6件（両方向36問）の計93問を生成します。教科書の配当は異なり、全範囲の網羅や特定教科書準拠は保証しません。

- `kind: kanji`：`word`・`reading`・`reading_dummies`・`sentence`で読み。`writing_hint`・`character`・`writing_parts`で構成部品を順に選ぶ。`writing_parts[]`には`position`（位置ラベル）、`answer`、`dummies`3件、`box:[x,y,width,height]`（100を全幅／全高とする位置）を保持する。全段階を1単位として連続回答し、未回答は伏せ、完成字形は最後に表示する。候補は部首名でなく字形。完成漢字は回答前の本文に書かない。読みの別の正答をダミーにしない（憧憬の「どうけい」は誤答にしない）。
- `kind: idiom`：`term`・`definition`と各方向3候補。正解の言い換え、上位概念に含まれる別の正答をダミーにしない。
- `kind: grammar`：理科と共通の`explanation_template`・`blanks`・`term_dummies`。
- 同じidの読み／書き・説明／用語・和訳／英訳は、別題材を挟んで出す。同じ説明文の複数穴は1単位として最後まで連続回答する。題材ごとの巡回順を固定し、科目別のシャッフルを混ぜる。英単語の文字綴りだけは1単位として順に連続回答する。熟語の穴は連続させない。

## 中2数学・中3社会のサンプル

- `junior_math.json`：中2図形12素材・13問。三角形の合同3条件、角の性質、平行四辺形などの暗記用。合同の「その間の角」「両端の角」、内角と外角、一般の平行四辺形と長方形・ひし形の追加条件を区別する。図や計算を伴う演習は含まない。
- `junior_social.json`：中3公民12素材・26問。憲法・国の政治・地方自治・人権と義務。教育の義務は保護者が子に教育を受けさせる義務として記載する。
- 理科と同じ素材スキーマを利用。数学は穴埋め（用語→解説）のみを生成し、解説→用語は出題しない。社会は2方向を生成。多角形の公式は2穴、三大義務は3穴を順に解く。各単元のサンプルであり、学年全体の網羅・特定教科書準拠を保証しない。

## テーマ表示と答えの漏えいを避ける編集ルール

説明文の穴埋めはテーマを表示する方を基本とする。`cloze_context`を未指定なら用語名を使う。テーマに解答が明記される場合だけ、その部分を伏せた文脈に言い換える。例：「三角形の合同条件（3辺）」は「三角形の合同条件」、「過去の助動詞『き』」は「古文の助動詞『き』」。`cloze_context_reason`に判断理由を残す。テーマが概念の手掛かりになるだけでは消さず、「基本的人権」のように対象を示すためのテーマは残す。新規素材にも同じ確認を適用する。

## 中学共通コンテンツの拡充（v0.45.0〜v0.46.1）

- `kind: choice`：`prompt`（設問）、`answer`、`dummies`（3件）、`task`（操作案内）、`note`（根拠・注意点）、`learning_point`（学習ポイント）を持つ一方向の問題。解法や読解のポイントに使用し、用語を当てる逆問題は生成しません。

- 今回の素材は中学共通知識と復習事項で、学年は暫定です。教科書の配当・掲載単元を確認したデータではありません。
- 全単元の網羅完了ではありません。[収録一覧](../docs/content/junior-inventory.md)と[未充足項目・拡充計画](../docs/content/junior-plan.md)を確認してください。収録一覧は `node scripts/content-report.mjs` で再生成します。
- `npm test` は追加データを含む全15学年コースの生成・絞り込み、4択、文字量、綴り、既存との重複、履歴、5分進行を検証します。構造テストは正解内容の保証にはならないため、作問内容の確認も行います。

## 数学の数値生成（v0.47.0）

- `numeric_generator` がある数学の `kind: choice` 素材は、同名の生成器で数値・正解・誤答・解説を組み立てる。JSON内の固定文は編集用の元例であり、通常プレイでは生成した文を使う。現在11素材、計296通りの有限の数値範囲。
- 通常プレイでは新規の問題選択時だけ生成し、直近の数値署名を避ける。誤答後や復習で生成し直さない。同じ素材ID・問題キーへ履歴を集計し、パターン数を総問題数に加えない。
- 生成器を追加・変更したら `tests/math-variants.test.js` で許可範囲全体について正答が1つであることと文字量を検証する。候補の数式は独立した計算処理でも評価する。解説は必ず生成した数値を参照する。
- 生成ルールの意味が変わる場合は生成器の版を更新する。旧回答は保存された実表示とパラメータで確認できるようにし、過去の記録を新しい数値へ置き換えない。
