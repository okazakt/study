# Study Beat

中高生向けの暗記学習 × 音楽ゲームのPWA試作。収録データは中3理科89件と「Fallin For You」1曲です。

```sh
npm start
# http://localhost:5173
npm test
```

外部パッケージ不要。起動にはPython 3、テストにはNode.js 18以上を使用します。スマートフォンからアクセスする場合や本番のPWA利用にはHTTPSが必要です（localhostは例外）。

4拍に1回のゆっくりしたノーツをタップします。白ノーツは5レーン（D/F/G/H/J）、回答中は4色固定の4列（D/F/G/H）です。白ノーツはどのレーンでも操作できます。回答時は毎回4色が同時に横一列で届きます。1列につき正解だと思う色だけを選び、累計3回タップし、誤答した場合も同じ問題を続けます。問題と選択肢は手元で一文字ずつゆっくり表示され、表示中はタップ不要です。全て出揃ってから上へ移動して回答モードになります。Spaceで一時停止します。

仕様、データ解釈、暫定ルール、未確定事項は [docs/pwa-spec.md](docs/pwa-spec.md) を参照してください。音源の同期ルールは [music-data/README.md](music-data/README.md) に従っています。

初回オンライン時のキャッシュ完了後にオフライン再生できます。学習記録はプレイ中のみ保持し、端末補正のみブラウザに保存します。
