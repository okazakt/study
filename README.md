# Study Beat

中高生向けの暗記学習 × 音楽ゲームのPWA試作。収録データは中3国語38件、中3理科89件（用語回答89問＋穴埋め97問）、中2英単語24件・熟語8件、中2数学12件、中3社会12件と「Fallin For You」「American Western Country」の2曲です。

```sh
npm start
# http://localhost:5173
npm test
```

外部パッケージ不要。起動にはPython 3、テストにはNode.js 18以上を使用します。スマートフォンからアクセスする場合や本番のPWA利用にはHTTPSが必要です（localhostは例外）。

1拍ごとのノーツをタップします。常時4レーン（D/F/G/H）です。白ノーツはシャッフルされた1レーンに流れ、そのレーンでタップします。回答時は毎回4色が同時に横一列で届きます。1列につき正解だと思う色だけを選び、累計3回タップし、誤答した場合も同じ問題を続けます。問題と選択肢は手元で一文字ずつゆっくり表示され、表示中はタップ不要です。全て出揃ってから上へ移動して回答モードになります。Spaceで一時停止します。

仕様、データ解釈、暫定ルール、未確定事項は [docs/pwa-spec.md](docs/pwa-spec.md) を参照してください。音源の同期ルールは [music-data/README.md](music-data/README.md) に従っています。

初回オンライン時のキャッシュ完了後にオフライン再生できます。問題別の回答履歴・正答数・誤答数と端末設定を、このブラウザのlocalStorageに保存します。サーバー保存や端末間同期はありません。

用語を選ぶ問題と説明文の「？」を埋める問題を出題します。複数の「？」は順に1つずつ問い、対象を強調します。次の「？」では本文を再表示せず、回答位置と選択肢を切り替えます。

問題のまとまりの間には、白ノーツ8回分の通常プレイを挟みます。候補の編集方針は [quiz-data/README.md](quiz-data/README.md) を参照してください。

選択肢の進捗は回数の数字ではなく、背景色が濃くなることで表示します。

英語は英語から和訳、日本語から英訳、綴りを順番に完成させる3形式を出題します。例：ground は gr → ou → nd。教科書によって配当学年は異なるため、中2向けの初期セットとして収録しています。

現在は Fallin For You / Flehmann → American Western Country / The_Mountain の順で連続再生します。曲間で回答進捗・得点・コンボを引き継ぎ、2曲目終了で結果を表示します。

熟語は単語単位の穴埋めです。take care ofなら「？ care of」「take ？ of」「take care ？」を順番に答えます。古い画面が残る場合はホームの「更新を復旧する」、または `update.html` を開いてください。タイミング設定と音源キャッシュを維持して本体を更新します。

中3国語38件を追加しています。漢字の読み・字形選択、熟語／四字熟語の両方向、現代文／古文／漢文文法の穴埋めと用語選択に対応します。同じ説明文の複数穴は最後まで連続回答し、逆方向と熟語の別位置には別題材を挟みます。英単語を前から完成させる文字綴りだけは連続します。

最終曲の残り時間に表示と最速回答が収まらない問題は出さず、白ノーツで終えます。複数穴は全穴分をまとめて見積もります。リズムコンボは手元、一発正解コンボも手元で連続成功の演出を表示します。

初回に中学／高校を選び、教科→学年または受験用→単元の順に選択します。学校と範囲は保存し、学校はホームの設定から変更できます。現収録は中3理科・中3国語・中2英語・中2数学・中3社会です。高校と未収録範囲は準備中。受験用は現収録分を使用し、画面に実際の範囲を示します。手元にはリズムコンボと「正解 N COMBO」を横並びで表示します。

国語は漢字書き・漢字読み・熟語・現代文法・古文・漢文・全て、英語は単語和英・単語英和・単語綴り・熟語和英・熟語英和・全てを選択できます。形式の指定は保存され、実際の出題方向にも反映します。

漢字書きは構成部品を最後まで順番に選びます。例：憧は忄→立→里、被は衤→皮。正解済みの部品を残し、全て選ぶと完成した漢字を表示します。

## 数学・社会のサンプル

中2数学は図形12素材・25問（合同条件、平行線と角、多角形、三角形、平行四辺形）。中3社会は公民12素材・26問（憲法、国の政治、地方自治、人権と義務）。どちらも説明から用語を選ぶ問題と説明文の穴埋めに対応し、単元で絞り込めます。各学年全体の網羅ではありません。

## 復習と学習レベル

結果の「間違えた問題を復習する」で、当回に誤答した問題段階だけを、音楽・アニメーションなしの4択で復習できます。正解するまで同じ問題を続け、○と解説の後に「進む」で進みます。誤答後に曲が終わった未完答も対象です。

プレイ上部は合計点と「学習レベル（参考）」、コンボは手元に表示します。学習レベルは現在教科・学年コース（受験用は教科の収録学年）の最近の正答率に基づく個人内の目安で、偏差値ではありません。30回答・異なる10問題から表示。復習回答は別に記録し、レベルに算入しません。保存履歴を使い、未経験や逆方向の未経験、誤答歴などのカテゴリを35:25:18:15:5:2で重み付き抽選します。空カテゴリは除外して比率を再計算します。

穴埋めのテーマ名は基本的に表示し、正答が直接書かれている部分だけを伏せた文脈に言い換えます。編集基準と例外理由は問題データに記録しています。

## 結果表示と自己ベスト

終了時は合計スコアを先に表示し、1.2秒後に詳細を表示します。合計スコア・最大リズムコンボ・最大一発正解コンボの自己ベストをこのブラウザに保存し、上回った項目に「自己ベスト更新」を表示します。同点・0点では更新表示しません。全コース共通で、途中終了も含め、この機能追加後のプレイから記録します。

## 履歴に応じた出題とセクションの進捗

未解答、誤答した問題の未経験の逆方向、正解した問題の未経験の逆方向、誤答歴あり、正解歴あり、直近3回一発正解の6カテゴリを使います。複数穴はまとめて選び、直近3題材を避けます（候補が少なければ緩和）。セクションと学年コースには「解いた X / Y問」を表示し、逆方向・空欄・綴り・部品を別問題として数えます。誤答だけでも解答済み1件とし、同じ問題への反復は件数を増やしません。

## 誤答ペナルティとカラーの得点

誤答確定でリズムコンボ・一発正解コンボの両方が0になります。カラーノーツはGOOD 1点／PERFECT 2点でコンボ分の得点加算はありません。白ノーツはGOOD 5点／PERFECT 10点＋コンボ数のままです。結果の復習ボタンは合計点の直下、「もう一度プレイ」は学習記録の直前に表示します。

タップ判定の中心はノーツの目標時刻です（PERFECT±80ms・GOOD±160ms）。一時的な−3ms補正は撤回しました。保存済み端末補正はそのまま適用します。別アプリから戻った後の「再開」では効果音の音声処理を作り直し、音楽・効果音の復帰を試みます。

## タイミングチューニング

ホームの「タイミングをチューニング」から、曲を0.5倍速で再生して拍をタップします。外れ入力を除き、32回以上の採用入力と安定性を確認しながら徐々に補正します。「通常速度で確認」で1倍速でも確認でき、安定したら「保存して適用」。出力（スピーカー／有線／Bluetooth／その他）ごとに保存し、次回から自動適用します。出力を変えた場合はメニューで選び直してください。

保存結果は「設定値をコピー」で共有できます。実機で試した結果を共通初期基準にする場合は、`calibration.js`の`DEFAULT_TIMING_OFFSET_MS`を次の公開版で変更します。現在は0ms。保存済みの絶対補正値は共通基準を上乗せせずそのまま使い、新しい出力だけが共通初期基準を使います。譜面・音源原本は変更しません。
