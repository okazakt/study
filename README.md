# Study Beat

中高生向けの暗記学習 × 音楽ゲームのPWA試作。収録データは中3国語38件、中3理科89件（用語回答89問＋穴埋め97問）、中2英単語24件・熟語8件、中2数学12件、中3社会12件と「Fallin For You」「American Western Country」の2曲です。

```sh
npm start
# http://localhost:5173
npm test
```

外部パッケージ不要。起動にはPython 3、テストにはNode.js 18以上を使用します。スマートフォンからアクセスする場合や本番のPWA利用にはHTTPSが必要です（localhostは例外）。

主拍を基本にノーツをタップします。白ノーツは見逃しも含む120回分の目標に合わせて増減し、必要時は拍の間にも追加します。常時4レーン（D/F/G/H）です。白ノーツはシャッフルされた1レーンに流れ、そのレーンでタップします。回答時は毎回4色が同時に横一列で届きます。1列につき正解だと思う色だけを選び、累計3回タップし、誤答した場合も同じ問題を続けます。問題と選択肢は手元で一文字ずつゆっくり表示され、表示中はタップ不要です。全て出揃ってから上へ移動して回答モードになります。プレイ中の一時停止はできません。別アプリ・別画面への切替や音楽の中断で、そのプレイは途中終了します。確定した回答履歴は残ります。

仕様、データ解釈、暫定ルール、未確定事項は [docs/pwa-spec.md](docs/pwa-spec.md) を参照してください。音源の同期ルールは [music-data/README.md](music-data/README.md) に従っています。

初回オンライン時のキャッシュ完了後にオフライン再生できます。問題別の回答履歴・正答数・誤答数と端末設定を、このブラウザのlocalStorageに保存します。サーバー保存や端末間同期はありません。

用語を選ぶ問題と説明文の「？」を埋める問題を出題します。複数の「？」は順に1つずつ問い、対象を強調します。次の「？」では本文を再表示せず、回答位置と選択肢を切り替えます。

問題のまとまりの間には、8主拍ぶんの通常プレイ（ノーツ数は120回目標で調整）を挟みます。候補の編集方針は [quiz-data/README.md](quiz-data/README.md) を参照してください。

選択肢の進捗は回数の数字ではなく、背景色が濃くなることで表示します。

英語は英語から和訳、日本語から英訳、綴りを順番に完成させる3形式を出題します。例：ground は gr → ou → nd。教科書によって配当学年は異なるため、中2向けの初期セットとして収録しています。

現在は Fallin For You / Flehmann → American Western Country / The_Mountain の順で連続再生します。曲間で回答進捗・得点・コンボを引き継ぎ、5分でフェードアウトして結果を表示します。

熟語は単語単位の穴埋めです。take care ofなら「？ care of」「take ？ of」「take care ？」を順番に答えます。古い画面が残る場合はホームの「最新版を読み込む」をお試しください。直接アクセス用の `update.html` も維持しています。タイミング設定と音源キャッシュを維持して本体を更新します。

中3国語38件を追加しています。漢字の読み・字形選択、熟語／四字熟語の両方向、現代文／古文／漢文文法の穴埋めと用語選択に対応します。同じ説明文の複数穴は最後まで連続回答し、逆方向と熟語の別位置には別題材を挟みます。英単語を前から完成させる文字綴りだけは連続します。

最終曲の残り時間に表示と最速回答が収まらない問題は出さず、白ノーツで終えます。複数穴は全穴分をまとめて見積もります。リズムコンボは手元、一発正解コンボも手元で連続成功の演出を表示します。

初回に中学／高校を選び、教科→学年または受験用→単元の順に選択します。学校と範囲は保存し、学校はホームの設定から変更できます。現収録は中3理科・中3国語・中2英語・中2数学・中3社会です。高校と未収録範囲は準備中。受験用は現収録分を使用し、画面に実際の範囲を示します。手元にはリズムコンボと「正解 N COMBO」を横並びで表示します。

国語は漢字書き・漢字読み・熟語・現代文法・古文・漢文・全て、英語は単語和英・単語英和・単語綴り・熟語和英・熟語英和・全てを選択できます。形式の指定は保存され、実際の出題方向にも反映します。

漢字書きは構成部品を最後まで順番に選びます。例：憧は忄→立→里、被は衤→皮。正解済みの部品を残し、全て選ぶと完成した漢字を表示します。

## 数学・社会のサンプル

中2数学は図形12素材・25問（合同条件、平行線と角、多角形、三角形、平行四辺形）。中3社会は公民12素材・26問（憲法、国の政治、地方自治、人権と義務）。どちらも説明から用語を選ぶ問題と説明文の穴埋めに対応し、単元で絞り込めます。各学年全体の網羅ではありません。

## 復習と学習レベル

結果の「間違えた問題を復習する」で、当回に誤答した問題段階だけを、音楽・アニメーションなしの4択で復習できます。正解するまで同じ問題を続け、○と解説の後に「進む」で進みます。誤答後に曲が終わった未完答も対象です。

プレイ上部は合計点と「学習レベル（参考）」、コンボは手元に表示します。学習レベルは現在教科・学年コース（受験用は教科の収録学年）の最近の正答率に基づく個人内の目安で、偏差値ではありません。30回答・異なる10問題から表示。復習回答は別に記録し、レベルに算入しません。保存履歴を使い、未経験や逆方向の未経験、誤答歴などのカテゴリを35:25:18:15:5:2で重み付き抽選します。空カテゴリは除外して比率を再計算します。

穴埋めのテーマ名は基本的に表示し、正答が直接書かれている部分だけを伏せた文脈に言い換えます。編集基準と例外理由は問題データに記録しています。

## 結果表示と自己ベスト

終了時は合計スコアを先に表示し、1.2秒後に詳細を表示します。合計スコア・最大リズムコンボ・最大一発正解コンボの自己ベストをこのブラウザに保存し、上回った項目に「自己ベスト更新」を表示します。同点・0点では更新表示しません。全コース共通で、途中終了も含め、この機能追加後のプレイから記録します。

## 履歴に応じた出題とセクションの進捗

未解答、誤答した問題の未経験の逆方向、正解した問題の未経験の逆方向、誤答歴あり、正解歴あり、直近3回一発正解の6カテゴリを使います。同じカテゴリ内では直近の連続誤答（誤答後に正解した回も含む）を優先し、同条件なら累計回答数が少ないもの、その次に最終回答が古いものを選び、完全に同条件のものをランダム抽選します。複数穴はまとめて選び、直近3題材を避けます（候補が少なければ緩和）。セクションと学年コースには「解いた X / Y問」を表示し、逆方向・空欄・綴り・部品を別問題として数えます。誤答だけでも解答済み1件とし、同じ問題への反復は件数を増やしません。

## 5分のプレイと結果画面

1プレイは現在5分です。2曲を続けて再生し、最後の3秒でフェードアウトします。タイマーは曲ごとに戻らず、プレイ全体の0:00 / 5:00を表示します。最短回答と全空欄の完了・正解表示がフェード前に収まらない新しい問題は出しません。結果の「ホームへ」は最上部にあり、詳細の表示を待たずに戻れます。

白1個、カラー4色同時の1列を1回とし、成功・見逃しのどちらでも120回の枠を消費します。空振りは枠に含めません。白ノーツは主拍を優先し、不足時は中間拍を加えます。見逃し分を追加することはありません。問題が長引いて調整できない場合は、問題回答と5分の制限を優先します。

## 満点固定の採点

満点は10,000点：白5,000点＋問題5,000点（カラー1,000点・正答4,000点）。開始時に同じ履歴・シードで全て一発正解する基準プレイを試算し、その回の問題数から1問あたりの配点を逆算します。PERFECTは判定点の100％、GOODは50％、見逃しは0％。カラーは各回答段階の最初の必要列数（現在3列）だけが加点対象で、以後は0点でもコンボは増えます。正答点はお手つき0／1／2／3回以上で100／80／50／0％。誤答確定とMISSは従来どおりコンボを切ります。

旧コンボ数による得点加算を固定満点の判定・回答成績へ統合し、コンボ表示と記録は維持します。実際の問題数・白ノーツ数が基準より増えた場合は大きい方で換算し、再挑戦や追加出題で満点を超えないようにします。空振りはリズム得点へ判定済み数／（判定済み数＋空振り数）の係数を掛けて減点します。プレイ中は暫定得点、結果には白・カラー・正答・空振り減点・基準問題数を表示します。

合計スコアの自己ベストは新基準用のキーに分け、旧得点の自己ベストとコンボ記録は残しています。

## 出題数の試算

`node scripts/compare-question-counts.mjs` で、各教科の表示時間が短い25％／長い25％の問題群を、全問一発正解・履歴なし・5分・各100回で比較できます。空欄・綴り・漢字部品の各回答段階を1問と数えます。

| 教科 | 短い問題群の平均 | 長い問題群の平均 |
| --- | ---: | ---: |
| 国語 | 12.2問 | 7.5問 |
| 英語 | 11.5問 | 8.6問 |
| 数学 | 8.7問 | 7.0問 |
| 理科 | 8.9問 | 6.4問 |
| 社会 | 8.8問 | 7.1問 |

`node scripts/simulate-session.mjs` は全形式混在の出現数と、成功・見逃しを含むノーツ判定数を集計します。4色の表示オブジェクト数は4個として数え、固定ゴーストは除外します。これらは実ユーザーの観測平均ではなく、選択範囲・回答速度・履歴により変わります。

タップ判定の中心はノーツの目標時刻です（PERFECT±80ms・GOOD±160ms）。保存済み端末補正を適用し、チューニングのみ一時停止・再開が可能です。

## タイミングチューニング

ホームの「タイミングをチューニング」から、曲を0.5倍速で再生して拍をタップします。外れ入力を除き、32回以上の採用入力と安定性を確認しながら徐々に補正します。「通常速度で確認」で1倍速でも確認でき、安定したら「保存して適用」。出力（スピーカー・有線ヘッドホン共通／Bluetooth／その他）ごとに保存し、次回から自動適用します。出力を変えた場合はメニューで選び直してください。

保存結果は「設定値をコピー」で共有できます。実機で試した結果を共通初期基準にする場合は、`calibration.js`の`DEFAULT_TIMING_OFFSET_MS`を次の公開版で変更します。現在の初期基準はスピーカー・有線ヘッドホン共通−101ms、Bluetoothとその他は0msです。保存済みの絶対補正値は共通基準を上乗せせずそのまま使い、新しい出力だけが共通初期基準を使います。譜面・音源原本は変更しません。

スピーカーと有線ヘッドホンの設定は共有します。旧版で有線が選択されていた場合は、その保存値を共通設定へ引き継ぎます。Bluetoothの保存値は独立して保持します。

問題ごとの累計回答数は「回答が確定した1出題」を1回とし、同じ出題での誤答・再挑戦で重複加算しません。最終回答日時と直近3回の一発正解／再挑戦正解／誤答終了、誤答回数・日時・最後の選択・通常／復習の区分を集計データへ保存します。古い履歴は復元し、詳細不足で累計が確定できないものには推定の印を残します。この集計は詳細イベント直近1万件の上限とは別に保持します。
